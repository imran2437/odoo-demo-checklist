Daily Task Checklist
====================

Odoo 19 app by Imran Odoo Consultant. Free; LGPL-3. Depends only on base.

Install the module, then open Daily Checklists > My Checklists > New.
Enter a title and due date, add tasks, and tick Done as work is completed.
Complete All marks every task done; Reset Tasks clears completion.
The status and progress are computed from the checklist's task items.
Use the Open filter to find unfinished checklists. Archive a checklist from
the standard Action menu when you no longer need it in the active list.

Internal users can create, read and modify only their own checklists in
their allowed companies. Superuser access follows normal Odoo behavior.
This app has no shared team task management, payroll, billing or external services.

Supports Community and Enterprise on Odoo.sh or self-hosted Odoo 19.
Custom Python modules cannot be installed on standard Odoo Online.
